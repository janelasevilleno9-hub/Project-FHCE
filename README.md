# Project-FHCE
Forecasting Household Consumption Expenditure using Time Series Analysis 

This repository was created as the final course output for MAT305 Mathematical Modeling. It contains data and code on Household Consumption Expenditure, published April 2, 2026. See below for details.

#Data Description
1. Source and Scope

The dataset used in this study represents the Household Final Consumption Expenditure (HFCE) of the Philippines. [FHCE_raw_data]

Source: Philippine Statistics Authority (PSA) via OpenSTAT.

Time Span: Q1 2000 to Q4 2025 (Actuals) 

Frequency: Quarterly.

Unit of Measure: Millions of Philippine Pesos (PHP), Constant Prices.
